# Stock Keeper Plus

Improvements for the Create 6.0.10 Stock Keeper request screen (NeoForge 1.21.1).
Create: Remote Terminal opens the same screen, so it gets the improvements too.
See the [main README](../README.md) for the features.

The mod works on the client alone. On the server it is optional: there it answers the client's requests
for gauges, containers and container contents (`server/`, payloads in `network/`).

## Build

```
./gradlew build
```

The jar ends up in `build/libs/`.

The first build runs `setupLibs`, which downloads the exact release jars from Modrinth (checked by SHA-1):
Create 6.0.10, Create: Remote Terminal, JEI and MezzConfig. Create's jar goes to `libs/` together with the
libraries bundled inside it (Ponder, Flywheel, Registrate) to compile against; all of them are also copied
to `run/mods/` for the dev client.

## Dev client and server

```
./gradlew runClient
./gradlew runServer
```

## How it works

- `ScreenSwapHandler` listens to `ScreenEvent.Opening` and replaces Create's `StockKeeperRequestScreen` with
  `StockKeeperPlusScreen`, a subclass. Create's JEI handlers (which JEI matches with `Class.isInstance`) and
  `menu.screenReference` keep working.
- Non-public parts of Create's screen are reached through mixin accessors in `mixin/`.
- `GaugeTracker` reads the Factory Gauges of the ticker's network from the block entities the client has loaded
  and caches them per world in `config/stockkeeperplus/gauges/`.
- Textures in `assets/stockkeeperplus/textures/gui/buttons.png` are generated by `tools/gen_buttons.py` (Pillow).

Parts of the code follow Create's own code (MIT license, Copyright simibubi and contributors).
